## ❓ TROUBLESHOOTING

**Error: "Permission denied"**
- Check your GitHub username is correct in the URL
- Make sure you're logged in to GitHub
- Try using SSH key instead (advanced)

**Error: "Repository already exists"**
- The GitHub repository name is already taken
- Use a different name: `mindmap-phase2-v2` or similar

**Error: "No such remote"**
- You haven't run `git remote add origin ...` yet
- Run the command to add the remote first

**Push is stuck**
- Check internet connection
- Press Ctrl+C to cancel
- Try again

**Can't find files on GitHub**
- Refresh your browser page
- Wait a few seconds (sometimes GitHub takes a moment)
- Check you're on the correct repository
