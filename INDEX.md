## 💬 FAQ

**Q: Is this really $0 to run?**
A: Yes. Render free tier (2 months free then always free tier), Featherless.ai sponsorship, IPFS/Arweave free. No costs.

**Q: Can this really work on all 6 channels?**
A: Yes. Caspian SDK handles channel abstraction. Single handler routes to all 6.

**Q: Is blockchain really necessary?**
A: No, it's optional (Phase 2). MVP works without it. But it enables verification + auditability + premium positioning.

**Q: Why passwordless auth?**
A: Simpler, more secure, faster to build, free. No password resets = happy users.

**Q: What if Featherless.ai is down?**
A: Graceful fallback to Ollama (local), then cached responses. Never just "ERROR".

**Q: Can I add more channels later?**
A: Yes. Caspian supports 10+ channels. Just add new handler + Deerflow workflow.

**Q: Is this GDPR compliant?**
A: Yes. User data stays on user's device/database. Optional blockchain backup is user choice.

**Q: How do I make money after hackathon?**
A: See post-launch roadmap in STARTUP_CHECKLIST. Premium features, team access, vertical-specific agents.
